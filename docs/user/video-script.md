# Getting-started video: script and shot list (≈ 5 minutes)

For recording with OBS or similar at 1920×1080. Uses the ops-review pack and a plain monthly deck.
Keep the cursor slow; zoom in on the Selection Pane and the workbook.

| Time | Screen | Voice-over |
| --- | --- | --- |
| 0:00 | A filled ops-review deck, flicking through slides | "This deck rebuilds itself every month from one Excel file. Here's how to set that up in about ten minutes." |
| 0:15 | DeckForge window, empty | "DeckForge runs on your computer. Nothing is uploaded." |
| 0:25 | Choose template → checklist appears | "Pick your PowerPoint template. DeckForge lists everything it can fill: tags, tables and charts." |
| 0:45 | Choose sample workbook → Generate → Open | "With the sample workbook, one click makes the deck. Charts are real PowerPoint charts — right-click, Edit Data, the numbers are there." |
| 1:20 | PowerPoint: type `{{oee}}` over 78.4% | "To use your own deck, replace a number with a tag in double braces. It keeps your formatting." |
| 1:50 | Selection Pane: rename table to `downtime`, chart to `oee_trend` | "Tables and charts just need a name: Home, Arrange, Selection Pane." |
| 2:20 | DeckForge: Create data file… → Excel opens | "Create data file builds the workbook for you — a kpis sheet for the tags, a sheet per table and chart." |
| 2:50 | Paste numbers; format a cell as 0.0% | "Paste this month's numbers. Format cells the way you want them shown." |
| 3:15 | Check → one problem with hint → fix → Check passes | "Check tells you exactly what's missing and how to fix it." |
| 3:40 | Generate → Open | "Generate." |
| 3:50 | client-monthly: batch column, Generate → three decks | "Reporting for many clients or plants? Add a batch column: one workbook, one deck each." |
| 4:20 | Save as recipe → sidebar → Run | "Save it as a recipe. Next month: update the workbook, click Run." |
| 4:40 | Closing card: download link | "Try it free with the template packs. Links below." |
