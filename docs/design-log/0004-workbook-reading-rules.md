# 0004 — Workbook reading rules (Lite)

- Date: 2026-11-11 · Edition: lite · Status: accepted

Additions to 0003, found while building `data-xlsx` and the CLI.

## Decisions
- **Empty value = missing.** A `kpis`/`meta` row whose `value` cell is empty is treated as if the
  row were absent, so a half-filled workbook (e.g. fresh from `init-data`) fails with
  "fill in the value for X" instead of silently producing blank text. `--missing blank` is the
  explicit way to allow blanks.
- **Excel number formats carry over.** When the `format` column is empty (or for table cells,
  which have no format column), a numeric cell's Excel number format is mapped to a DeckForge
  format: `0.0%` → `percent:1`, `$#,##0` → `currency:0`, `#,##0.00` → `number:2`, date formats →
  `date`. Users format cells in Excel the way they want them shown. The currency *symbol* is not
  inferred; the run's `--currency` decides it.
- **Reserved and ignored sheets.** `kpis` and `meta` are reserved names (a table or chart with
  either name is an error). Sheets whose name starts with `_` are ignored, so `init-data` can
  include a `_readme` sheet and users can keep notes.
- **Blank rows are skipped** anywhere in table and chart sheets (Excel's used range often runs
  past the data).
- **Chart series are the contiguous headed columns from B**; the first empty header ends them.
- **Formulas** use their saved result. A formula with no saved result (workbook generated by a
  tool and never opened in Excel) is an error telling the user to open and save it.
- **`batch` column**: an error until batch mode lands in L2, so rows for several plants are
  never silently merged into one deck.
- **Not a workbook**: ExcelJS opens any zip, so a workbook with no worksheets is rejected as
  "not an Excel workbook".

## Deferred
- CSV input (one CSV per sheet in a folder) — after L1, when a services job needs it.
